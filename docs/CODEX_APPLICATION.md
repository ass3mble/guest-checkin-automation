## Why does this repository qualify? (500 characters max)

Guest Check-in Automation is an MIT-licensed Python project I actively maintain
and use for real hospitality check-in workflows. It connects web forms, OCR,
SQLite, Telegram review, Beds24 and optional smart locks. The public repository
has documented releases, automated tests on Python 3.11/3.12, security guidance
and contribution instructions. Its goal is to make reliable, privacy-aware
automation reusable for small accommodation operators.
